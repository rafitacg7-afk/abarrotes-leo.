# Abarrotes Leo

Aplicación web instalable para controlar inventario, ventas, clientes, proveedores, compras, abonos y reportes en una tienda de abarrotes.

## Activar publicación gratuita

1. Abre **Settings → Pages** de este repositorio.
2. En **Build and deployment → Source**, elige **GitHub Actions**.
3. Guarda. El flujo de despliegue está en `.github/workflows/pages.yml` y publicará el sitio tras una ejecución correcta en Actions.
4. Revisa la pestaña **Actions**. No compartas el enlace como listo para uso real hasta comprobar que el despliegue termine en verde y la app abra correctamente.

## Instalar en el celular

- Android: abrir el enlace en Chrome y usar el menú ⋮ → **Instalar aplicación** o **Añadir a pantalla de inicio**.
- iPhone: abrir el enlace en Safari → **Compartir** → **Añadir a pantalla de inicio**.

## Datos y seguridad

- En esta versión, los registros se guardan en el navegador del dispositivo y no se sincronizan en la nube entre teléfonos.
- Cada teléfono empieza con su propio almacenamiento. Usa **Ajustes → Exportar respaldo** y **Importar respaldo** para trasladar registros.
- No subas respaldos con información personal o de clientes al repositorio público.
- Verifica manualmente inventario, ventas, compras y restauración de copias antes de usarlo en operaciones reales.
